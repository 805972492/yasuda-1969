# maps/ · 三张地图，别搞混

| 文件 | 是什么 | 时间基准 |
|---|---|---|
| `安田讲堂攻防战地图.html` | **构内战术图**：47 栋建筑轮廓 + 16 个编组 + 39 条事件，滑杆按 1/18 00:00 起的分钟推进 | 1969-01-18/19 |
| `1969地形复原图.html` | **1969 年配置复原**：在现代 OSM 轮廓上叠加「现存／已拆／后建」判定，附安田讲堂立面剖面 SVG | 1969 年，推定 |
| `东京全城态势图.html` | **全城联动**：本乡／神田／御茶之水／驹场 108 条事件、20 个派系、12 条影响 | 1/15—1/29 |

三张都是单文件 Leaflet 页面，双击即开（`file://` 可用；GeoJSON 已内联，不依赖本地服务器）。时间轴为绝对分钟数，滑杆下方会显示对应时刻。

## 底图与署名

- 默认底图：**国土地理院** シームレス写真（https://maps.gsi.go.jp/development/ichiran.html），页面右下保留「国土地理院」字样，请勿删除。
- 可切换：**OpenStreetMap**（© OpenStreetMap contributors，ODbL）、地理院标准图。
- 建筑轮廓来自 OSM（ODbL），1969 年配置的推定部分是整理者的工作结果（CC BY 4.0）。

## 已知限制

- 现代 OSM 上缺 1969 年已拆建筑（法文 2 号馆、理学部 2 号馆等）的轮廓，图上用**虚线圈＋推定矩形**表示，并在 popup 里标 `推定`。
- 地理院瓦片偶发限流，zoom 18 偶尔缺块，缩到 17 即恢复。
- 1969 年校园图不存在可叠底的官方测绘图（详见 `docs/10`），所有「1969 位置」都是按史料方位推的。
