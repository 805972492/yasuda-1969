# 安田讲堂攻防战：数据说明

本目录是 Gentactix-DSH 结构的战役包，供 RAG（corpus）与几何裁决（adjudication + geometry）使用。

## 与仓库其它战役的差异

- 尺度不同：其它战役是数十至数百公里的运动战；本战役是 **0.4 km × 0.5 km 的构内攻防**，故 `geometry` 以 0.05/0.04 km 为单位。
- 目标不同：攻方不是求歼，而是 **逐馆解除→逐层制压**；故 timeline 以「馆/层」为进展单位。
- 证据密度不同：本战役有官方逐日日志（S1）＋当事者回忆（S34）＋研究（S35），可交叉之处远多于普通战役，但也因此**异文更多**（见 figures 的 source_conflict 行）。

## 三条纪律

1. `null` 表示未核得，不得填 0，不得反推确数。
2. `source_conflict` 行只并列，不裁决；演示里也不许把两说合成一数。
3. hp/兵力/士气不是史料值，是教学初态；在界面上必须与史料数字分栏显示。
