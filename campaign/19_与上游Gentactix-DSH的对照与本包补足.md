# 与上游 Gentactix-DSH 的对照，以及本包的补足

用户要求：以 https://github.com/snow-wind-001/Gentactix-DSH 的开源模型为标准，补足差距；同时「全共闘方要可以控制所有与警察和民青对抗的活动，而不是只有安田讲堂里的人」。

本文件记录两件事：**上游有什么**、**这一版补了什么 / 还差什么**。检查基准是仓库 `E:\Gentactix-DSH\gentactix\` 里的实际代码（不是 README 的描述）。

## 二、本轮因「全域可控」而新增的东西

1. **三个战区**：本郷構内 / 神田・御茶ノ水 / 駒場。地图右上三个按钮切换，所有据点与编组都在同一套状态里结算。
2. **全共闘全域编组**（不是只有讲堂里的人）：
   - 神田街垒队 800 人（19 日 09:00 过夜部队，10 处街垒、12:50 拦停都电）
   - 明大駿河台泊込队 300 人（18 日 09:35 自此处出发袭派出所）
   - 駒場第 8 本館队 100 人（长期封鎖，15 日民青来攻）
   - 本郷増援（日大・他大）450 人
3. **民青作为独立敌对势力**：教育学部 300、第 2 食堂 150、医学部本館 200、駒場第 1・2 本館 300；每回合自动加固（+4 街垒），对 60 m 内的全共闘编组反击（−4 人、−5 士气）。
4. **全共闘可对警察与民青同时下命令**：突击/出击/放水·催泪/死守/修补/反击/转移/撤退/休整。实测可以把御茶ノ水站前派出所（機動隊）与駒場第 1・2 本館（民青）都打下来。
5. **台账页**：27 个编组的人数、损失、士气、补给、命令一屏看全；完整性告警单独列。
6. **复盘页**：易手记录（时间 + 从谁到谁）+ 被捕/清剿累计 + 告警数。

## 三、仍然差着的地方（说清楚，不粉饰）

- **不产伤亡**：上游同样不裁伤亡，但上游有 `figures.csv` 的史料值与 `reporting.py` 的摘要；本包只展示史料值，不推算。
- **无命令队列**：一次只能给每个编组挂一条命令，没有「先机动再突击」的多步队列，也没有修订号（上游 `check_revision`）。
- **无装备账**：编组只记人数与士气，没有枪械/车辆/催泪弹的个体台账。
- **无反事实对比**：不能「同一初始态跑两次不同决策并排比较」（上游 `causal.py` 有这个方向）。
- **补给不走路网**：没有 OSM 路网连通性判定，只有数值衰减。
- **AI 是规则不是模型**：民青与本方警察都是规则驱动，没接 DeepSeek（上游的「模型生成初态」在 `engine.py`，本包离线可跑，不依赖 API）。

## 六、第二轮补足（逐层控制 + 战报 + API）

| 上游能力 | 本轮实现 | 说明 |

## 九、文字与「直升机能力」（第五轮）

1. **显示文字全部改成简体**：界面、编组名、据点名、战报、结构页、README、战报示例统一为简体（localize_simplified.py 是转换器，可重跑）。机動隊→机动队、全共闘→全共斗、安田講堂→安田讲堂、列品館→列品馆、本郷→本乡、駒場→驹场、階→层、・→·。
2. **引文出处保留日文原题**：sources.json 的 	itle 与 liases 不转（要能对回『紛争日誌 その4』『島泰三『安田講堂 1968—1969』』等原题），其余说明字段转。
3. **直升机的能力修正**：原先 caps() 只给「休整/侦察」，仍在 log 里报「不具备 assault」；现在明确为 **侦察敌情 / 撒催泪液 / 休整**，并新增「空中平台只能压制、不能占领」规则——撒催泪把街垒压到 8 就停，不改变归属；对讲堂只能压某一层街垒，不占楼层。实测：对列品馆连续 30 次撒催泪，街垒 80→8，归属仍为社学同 ML 派；突击命令仍按回执退回。
