# 怎么玩：安田讲堂攻防战（1969.01.18—01.19）战役推演

双击 `推演展示_安田讲堂.html` 即可在浏览器里打开（单文件、无需服务器；卫星底图走地理院瓦片，联网时才有影像）。

## 1. 两种模式

- **剧本回放**（默认）：时间轴按史料自动推进，每回合 30 分钟，从 1969-01-18 06:30 到 01-20 06:00，共 95 回合。只看不下令，用来复盘。
- **自由推演**：点「切到自由推演」，你指挥一个阵营，结果由命令、几何与街垒数值决出。

## 2. 三个战区与全域控制

地图上方三个按钮切换战区：**本乡构内 / 神田·御茶之水 / 驹场**。同一套状态、同一本台账：

- 本乡：安田讲堂（逐层 1F—6F）、工学部列品馆、法学部研究室（法研）、法文 2 号馆、医学部综合中央馆、医学部本馆（民青）、工学部 1 号馆、教育学部（民青）、理学部 1 号馆、第 2 食堂（民青）
- 神田：神田街垒（10 处，全共斗 800）、明大骏河台（全共斗 300）、御茶之水站前派出所（机动队 40）
- 驹场：驹场第 8 本馆（全共斗 100）、驹场第 1·2 本馆（民青 300）

**「指挥 全共斗」是默认视角**：讲堂里、本乡各馆、神田街垒、明大、驹场第 8 本馆的编组你都能下令；对手包括机动队与民青（民青会自己加固与本方反击）。也可以点「指挥 机动队」反过来打。全共斗的「指挥键」覆盖反帝学评／社学同／社学同 ML 派／中核派／革马派／明大共斗——**同一阵营的不同组织都能下命令**。

3. **民青在史实里受警方保护**，所以警方 AI 不把民青据点列进目标清单；玩家若指挥全共斗，仍可以打民青（1/9、1/6 就是这么打的）。

## 4. 命令（按编组能力给，做不到的命令会被退回并写进战报）

全共斗：

| 命令 | 作用 |
|---|---|
| 出击（选点） | 向目标据点机动；接触后逐层/逐点进攻 |
| 死守加固 | 给所在据点 +5 街垒（讲堂给最低未失守层） |
| 修补街垒 +9 | 大幅加固（约两回合量） |
| 反击附近 | 90 m 内的敌方编组 −7 人、−8 士气 |
| 转移（选点） | 只机动，不接战 |
| 撤退 | 脱离接触退回本战区 |
| 休整 | 回士气 +6、补给 +8 |

机动队：

| 命令 | 作用 |
|---|---|
| 突击（选点） | 向目标机动；接触后扣街垒，扣到 0 才易手 |
| 放水·催泪 | 同样的接触判定，威力 ×0.62（压制为主） |
| 包围 | 250 m 内最近的敌方据点被封锁 2 回合：守方不能修补街垒、反击威力减半 |
| 转移（选点） | 只机动，不接战（2026-11-20 补：原来没有这条，只能靠攻击命令被动挪动） |
| 逐层下令 | 见 §6 |
| 休整 | 回士气 +6、补给 +8 |

**直升机的命令只有三条：侦察敌情 / 撒催泪液 / 休整**。它是空中平台，没有地面分队去占楼、抓人，所以系统不发给它「突击」能力——真下令突击，战报会写「不具备『assault』能力，命令退回」。撒催泪液也只能把街垒压到 8，占领仍要地面部队进入。

**撤退只执行一次**：撤完命令自动清空，不会每回合重复掉士气。

民青由 AI 运行（加固 + 反击），不受你指挥。

## 5. 面板

- **推演**：时钟、逐层控制表（1F—6F 的守方或「派系＋混成」、人数、街垒）、选中编组的命令按钮、我方可控编组列表、战报（含「回执」与「【史】」两类行）。
- **台账**：27 个编组的人数、损失、士气、补给、当前命令；底部显示完整性告警数。
- **结构**：安田讲堂立面剖面（见 §8）。
- **事件**：62 条史料时间点，带 S 编号。
- **数字**：16 条官方数字与异文，带 evidence_status（`published_account` / `source_conflict` / `unverified`）。
- **复盘**：每次易手的时间与「从谁到谁」、被捕/清剿累计、完整性告警明细。
- **说明**：本包的结构、几何参数、势力归属与边界。

## 6. 逐层下令（安田讲堂 1F—6F）

切到「自由推演」并选「指挥 全共斗」或「指挥 机动队」后，右侧「安田讲堂 · 逐层」的六行可以**直接点**：

- 选中某层（行会高亮），表下出现该层的命令按钮。
- **守方（全共斗 / 反帝学评 / 中核派）**：`加固 +9 街垒`、`该层反击`（对 120 m 内的机动队造成 5+街垒/20 人的杀伤、士气 −7）、`增援`（从本战区其它编组抽 10 人上来）、`撤离`（守备队与 40% 街垒退到上一层）。
- **攻方（机动队）**：`定向突击该层`（下层未清时只能施压，威力 ×0.55，并在战报里注明「受阻」）、`压制该层`（街垒 −12，不占地）。
- 攻方单位必须距讲堂 ≤120 m 才能对该层下令，否则先「突击（选点）」靠近。

## 7. 战报：规则摘要 + 接入 DeepSeek API

「战报」标签页有两条路：

1. **规则战报（离线可用）**：每回合自动生成一条「回合摘要」，记录本回合发生的攻击、街垒变化、据点易手、命令回执与告警。它不含任何生成式内容，逐条可对回状态。
2. **API 战报（要 key）**：在页面上填 Base URL（默认 `https://api.deepseek.com`）、模型（默认 `deepseek-v4-flash`）、API Key，点「生成本回合战报」。页面会把**当前真实状态**（时刻/回合、六层归属与街垒、各据点、在场编组人数士气补给、累计被捕与制压数、最近 6 回合摘要）打包给模型，system 提示里明令：只许依据状态写、不得虚构数字与人名、不确定写「未详」、3—5 句、≤400 字。

- Key 只存在本机 `localStorage`（键名 `yasuda_api`），不写进 HTML 文件；换机器或清缓存后要重填。
- 模型是推理型（返回里带 `reasoning_content`），页面把 `max_tokens` 放到 2400；若仍触上限，战报末尾会标注「被截断」。
- 「每回合自动生成」按钮：每 2 回合自动调一次 API（会产生费用，实测单次约 1,900—2,400 tokens）。
- 实测样例（第 16 回合、01-18 14:30）：模型写「…本回合机动队制压法学部研究室（法研），工学部列品馆街垒降至 8，教育学部街垒降至 40；第 3、第 4 机动队向第 2 食堂机动 210 米…累计被捕或清剿 476 人，制压据点累计 4 处」，与面板数字逐项对得上。

- 西（左）是本乡台地·正门侧，东（右）是崖下·御殿下侧，虚线标出 3 层与 1 层约 6m 的高差；

**合并**（人多以后威力按 √n 放大）：

| 操作 | 位置 | 效果 |
|---|---|---|
| 合并本战区同阵营编组 | 结构页底部 | 把本战区本方前两个编组合成一个（人数相加、士气补给取均值、番号合并） |
| 合并选中层各派 | 结构页/逐层按钮 | 5F 的「反帝学评＋社学同」合并成统一「全共斗」指挥 |
| 把上一层并入选中层 | 结构页/逐层按钮 | 把上层守备队抽下来并入本层（人数相加、街垒转移 50%），上层变空 |

## 9. 地图与标注

- **缩放范围 13—18 级**：初始 17 级，可以再放大一级（18 级）看清标签，也可以缩到 13 级看全城（神田·驹场在最外圈）。
- **每个据点与编组都有两层标签**：第一行是**地点／番号**，第二行是**组织＋兵力**（例：「工学部列品馆 / 社学同 ML 派｜50 人」）。
- 标签按屏幕像素**避让**：会先试上方、再试更上方、再试下方，被挤到 60px 以外时画一条细引线指回据点；实在放不下就只留悬浮提示（鼠标停上去仍有全量信息）。
- 16 级以下只画据点、17 级以上才加编组标签；切战区只画该战区的标签（安田讲堂始终显示）。

## 10. 这个模型不做什么

- **不算伤亡**。裁决器只裁机动、接触、街垒、逐层易手、人数账；伤亡数字在「数字」页是史料值，不是推演结果。
- **不做单兵与风向**：30 分钟一步、战役级粗粒度。
- **不确定处留白**：一层 40 人、二层约 30 人；5F/6F 只有派系没有人数（台账写「人数未详」）；18 日中止 17:30（S1）/17:10（岛泰三）、19 日结束 17:45/17:46、检举 633/983 等并列不取平均。
