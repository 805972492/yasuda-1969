# 安田讲堂攻防战（1969-01-18/19）· 史料整理与推演包

1969 年 1 月 18—19 日，警视厅以约 8,500 人解除东京大学本乡构内被学生占据的安田讲堂等建筑。这个仓库把它做成**可核对的资料集 + 可玩的推演包**：分钟级时间线、双方编成、逐栋归属、官方数字与异文，以及一个单文件推演页和一个 Gentactix-DSH 战役包。

> **这不是史料全集。** 仓库里没有扫描件、没有整本电子书、没有 NHK 节目表截图。所有原文都只做摘录并给出链接，复核请自行取用。

**在线试玩**：https://805972492.github.io/yasuda-1969/ （GitHub Pages；根目录 `index.html` 就是推演页，卫星底图需联网）

## 项目介绍

**它解决什么问题。** 安田讲堂攻防战的中文资料大多是二手叙述，数字彼此冲突（逮捕 633／983、讲堂内 397／374、18 日中止 17:30／17:10），而一手材料是日文的官方逐日日志、国会答辩和当事者回忆。本仓库做三件事：

1. **把来源排开**：S1—S46 登记表，每条注明出版者、类型、能支持什么，可信度分 A/B/C/D；有异文的地方并列，不取平均、不裁「正确值」。
2. **把事实对齐**：1 月 1—14 日的前史、1 月 18—19 日的分钟级时间线（含日誌逐条校勘与六处改正）、逐栋归属与逐层配置、双方的编成与装备。
3. **把材料变成可推演的东西**：一个 30 分钟一回合、能逐层下令、能接入 DeepSeek 生成战报的单文件演示；以及一套符合 Gentactix-DSH 数据结构的战役包（scenarios / sources / timeline / forces / figures / corpus / adjudication / anchors），可直接挂进该程序。

**给谁用。** 想核对细节的读者（`docs/`）、想做教学或复盘的人（`campaign/`）、想扩展自己推演系统的人（`integrations/`）。

**边界。** 不产出伤亡估计；不模拟单兵、风向与催泪气体扩散；30 分钟一步，分辨不了同回合内的先后。史料缺失处一律写「未核得」，不填 0。

## 数据口径（重要）

本仓库坚持「**并列，不取平均**」：

- **逮捕数**：警视庁 633（其中东大生 38）／另一说 983／逐日 273＋469＝742／构内 817 —— 五个口径并列，见 `docs/05`。
- **讲堂内人数**：397（島泰三）／374（小熊英二）／「约 400」—— 三说并列。
- **18 日中止时刻**：17:30（紛争日誌）／17:10（島泰三）—— 两说并列。
- **null 就是未核得**，不填 0、不反推确数。
- 推演里的兵力、士气、街垒是**教学初态**，不是史料值；界面把两者分栏显示。

## 会与不会

- **会**：逐馆/逐层推演、命令能力门控、移动步长与接触判定、空中平台只能压制不能占领、包围断补给、战报（可接 DeepSeek API）。
- **不会**：不产出伤亡估计；不模拟单兵、风向、催泪气体扩散；30 分钟一步，分辨不了同回合内的先后。
