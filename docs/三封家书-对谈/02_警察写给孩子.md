# 02 · 警察写给孩子

一九六九年一月十九日 凌晨
本富士署 临时警备本部

给女儿：

你睡觉的时候爸爸在写这封信。写完大概也不会寄出去——你们学校看得懂字了，我怕你拿给老师看。

十八日早上六点半，我们进了东大的门。一件事先说明：不是我们想进去，是学校自己打的电话。前半年的纠纷，学校忍了半年，到最后连电都自己掐了、水都自己停了，才叫我们。这个顺序，爸爸希望你记一辈子。

总共有八千人，加上五百个穿便衣的。爸爸是第八个队里的，我们这一队负责法学部那边。

我先说一件你可能不爱听的事：里面那些人，大部分和你哥哥差不多年纪。有几个我一看就知道，是乡下考出来的孩子，穿着和别人一样的头盔、一样的毛巾，脸冻得发白。十八岁、十九岁、二十岁。我们把水龙带架上去的时候，有人从窗口探出头来喊什么，风大，听不清。后来我才知道，他在喊"里面有人受伤了"。

列品馆烧起来的烟，我在两百米外都看得见。有人放火，也有人救火——我们的人提着灭火器往里冲，冲进去的不是去抓人，是去找火。这话没人会写进报纸，但我写给你。

那天晚上我们退出来的时候，我坐在装甲车后面的泥地上吃冷饭团，手抖得捏不住。旁边的年轻人问我：队长，他们为什么非要守在里面？我说不知道。其实我知道一点：如果我是二十一岁，如果那年头有人告诉我，世界上有一条比考试更值得走的路，我大概也会走进去。

爸爸年轻的时候，战后那几年，肚子是空的。我们要的是米、是工作、是能活下去。他们要的不是这些。他们什么都有，所以才要一样我们那时候没有的东西——一个说法，一个"我为什么活着"的说法。爸爸不懂那个说法，但爸爸知道，一个人为了一个说法愿意挨水龙带、挨瓦斯、愿意从五层楼上被架下来，那这个说法对他就是真的。

女儿，爸爸不是要你将来去做这种事。爸爸是想让你知道：这世界上有一种人，会在冬天里守一栋空楼，不是为了打赢，是为了不承认自己是空的。你长大后如果遇到这样的人，先别骂他蠢。

妈妈问起就说爸爸在加班。抽屉第二层有你的手套，别忘了戴。

父
一月十九日 凌晨三时

（这封信写在本富士署的便笺上，没有信封，也没有寄出。它被夹在警备记录簿里，战后由家属保存。）
