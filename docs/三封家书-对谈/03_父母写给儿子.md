# 03 · 父母写给儿子

一九六九年二月四日
长野县 · 家里

给儿子：

这封信我们不寄了，你说过不必来看你，我们就照着做。写下来是因为你母亲这半个月夜里总醒，坐着说话，说到天亮。写下来放在你房间，等你回来自己看。

一·一八那天，我们从电视上看到你在的地方。

电视里在放水，白花花的水柱，往五层楼上冲。你母亲说那不是你的窗。我说是。她知道。她只是不肯承认。

第二天报纸上的照片，是放水的正面照，讲堂前面一片白。我从头看到尾，没有看见你。到现在我也不知道该庆幸还是该难过。

一月二十日，文部省正式决定，今年东大的入学考试不办了。你父亲当天在单位听见同事说了句"闹成这样，考什么考"，端起茶杯的手停了一下。我们不是不气你——是气不上来。

这半年，我们不是没劝过。

你说过：你们那一代什么都有了，所以才会为了一点没有的东西去拼命。这话是我说的，说的时候以为很聪明。可这半年我常想，我们那一代真的什么都没有吗？我们有过战前、有过空袭、有过配给、有过那种"明天可能就没有了"的日子。我们靠不往前看、只往前挪一步活下来。你们不一样，你们往前看，看见的是四年以后进公司、十年以后课长、二十年以后一间房子和两个孩子。你们说那不是活着，是"被安排好了的活着"。

我们不懂。可我们也不是完全不佩服。

你母亲说，一个二十一岁的孩子，在冬天里守着一栋楼，守到最后一层，被人家从五层楼的屋顶上带下来——这不是我们教出来的，但也不是丢人的。我不知道这话对不对，但我一个字也没反驳。

有几件事要告诉你。

一，你的书我们没有扔，装箱了。那套《经济学原理》你母亲单独包了一层纸。
二，学校来信了，说过些时候会有处分，也说了会等审判。我们去找过一位律师，姓什么不重要，他说你这种情形要拘留很久，判决也许要到明年、后年。他说这句话的时候没有安慰我们，我们也没要安慰。
三，你父亲身体还好，只是那天在门口站得太久，膝盖又疼。邻居里有说闲话的，也有人说你"有骨气"。这两种话我们都不接。
四，你养的那盆植物，活下来了。

儿子，最后说一句我们说不出口的话。

我们不认为你是坏人。我们只是不知道你在争什么，争的东西值不值这么多。可你既然已经这样了，就好好把它说清楚——在法庭上，在信里，在你能说话的地方。别为了让我们安心就说自己后悔了。你不用说后悔。你要说真话。

家里一切都好。等你回来。

父　二月四日
母　附笔：天冷，袜子放在包里了，虽然不知道能不能送到你手上。
