# 06 地理与建筑

## 一、东京大学本郷构内的空间结构（1969 年）

本郷构内大致呈南北长、东西窄的不规则形，北为農学部・工学部，南为医学部・経済学部，中央偏东是**安田讲堂**与**御殿下グラウンド・三四郎池**，西侧沿本郷通り一线是**正門（赤門通り側）**与**赤門**（南西角）。主要通路：

- **正門**（35.712941, 139.759660）——本郷通り侧主入口，进门即银杏并木（銀杏並木），直通安田讲堂正面。
- **赤門**（35.710592, 139.760359）——南西，通往法学部・経済学部。
- **竜岡門**（医学部北侧，推定 35.7107, 139.7645）——18 日 07:03 机动队由此入构。
- **池の端門**（东侧，推定 35.7108, 139.7656）——同日入构。
- **農学部正門**（北侧，推定 35.7157, 139.7628）——18 日 06:50 首批入构。
- **弥生門**（北东，推定 35.7147, 139.7647）——07:12 拆除バリケード。

> 推定坐标只用于地图定位，不作史料依据。史料仅确认"从某门入构"这一事实。

### 攻防中的空间要点

1. **正面（西侧）**：面向银杏并木与正門，是正门大台阶与正面玄关；机动队 1/18 15:20 从此正面攻击，16:20 以电气ノコ破门。島泰三指此处为"来自所有方向的死角"（S14）。
2. **背面（东侧）**：邻御殿下グラウンド，1/18 15:30 约 50 名队员从背面两处突入，是突破口。
3. **南侧／北侧**：1/19 07:00 南北两路夹击；南侧 2→3 楼楼梯是 13:50 的激战点。
4. **3 楼大讲堂**：1/19 15:00 前后在此一次逮捕 200 人以上，是"主厅即主战场"。
5. **5 楼南侧屋顶 / 6 楼阳台**：16:30 反帝学評与社学同在此集合、合唱、演说。
6. **时钟塔（時計塔）**：顶层标志物，17:27 被突入，17:45 塔顶数人被捕——事件的最后画面。
7. **内部通道**：庶務部入口（1/18 13:20 装甲车接近处）、学生部（1/19 12:55 推进点）、事务局（19:00 检证起点）。

## 四、20 世纪 60 年代与现在的地形差异（做地图必读）

1. **列品館並非"已拆"**：工学部列品館（1925、RC 3 阶建、766㎡）現存，今为工学部本部，1998 年登录有形文化财；OSM 只是缺它的多边形，地图中以"推定位置"标注（S22）。纷争日志记"2・3・4 阶起火"，与登录档"3 阶建"的差异按塔屋部分解释（S1）。
2. **法文 2 号館**：现 OSM 虽无法文 2 号館多边形（可能已改称或合并），按史料相对位置推定于法文 1 号館东北。
3. **御殿下グラウンド** 1969 年为运动场，现为御殿下記念館与地下设施，讲堂背面（东侧）的接近路因此变化。
4. **树木与视线**：銀杏並木当时比现在稀疏，正面视野更开阔。
5. **道路**：本郷通り、赤門通り走向基本未变，可放心用现代底图定位。

## 五、坐标与许可

- 坐标系：**WGS84**（OSM 标准）。日本国内地图（国土地理院）为 JGD2011，与 WGS84 差异 < 1 m，本用途可忽略。
- 建筑轮廓数据：OpenStreetMap，许可 **ODbL 1.0**（署名 + 相同方式共享）。文件：`data/key_buildings.geojson`（47 个多边形）、`data/osm_points.geojson`（地名点）。
- 使用 OSM 时应标注：`© OpenStreetMap contributors`。交互地图中已内置该署名。
