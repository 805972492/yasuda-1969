## 三、可信度分级（全文通用）

| 级别 | 含义 | 例子 |
|---|---|---|
| **A 一手·官方** | 当事机关原始记录 / 国会答辩 / 政府白皮书 | 東京大学「紛争日誌」、国会会議録、犯罪白書 |
| **B 一手·当事者** | 现场指挥、参与者的回忆与著作（有立场） | 佐々淳行『東大落城』、島泰三『安田講堂』 |
| **C 当时报道** | 1969 年前后的报纸、通讯社、外电 | 朝日、毎日、共同通信、NYT |
| **D 事后综述** | 百科、回顾报道、研究论文 | ja.wikipedia、産経「警視庁150年」、Japan Times 特集 |

**使用规则**：A 用来定锚（时刻、数字、番号）；B 用来补细节但要标注立场；C 用来互证与补现场感；D 只当索引，不单独作为唯一依据。凡 A 内部互相矛盾处（如逮捕总数），`05` 里一律并列，不做单一结论。

## 四、四个必须知道的口径问题

1. **机动队人数**：8,500（東大日誌、共同、産経、日経）vs「七千人ぐらい」（警察庁長官官房長 浅沼清太郎国会答辩）。差额可解释为「8 个机动队 8,000 人＋私服 500 人」是否计入。岛泰三给出 8,513 人＝8 个机动队 4,678＋另两方面 2,565＋预备与干部 1,000 余（S34）。
2. **逮捕/检举总数**：東大日誌逐日加总为 273（1/18 本郷）＋469（1/19 大講堂）＋75（1/19 神田）＝817；警視庁记录 633；岛泰三合计 682；小熊引述 983（讲堂内 374）。**五说并列**，`05` 逐条注口径，禁止单取。
3. **起诉人数**：509 是 1969-03 时点（西郷法相答辩），607 是最终（最高裁刑事局），590 是一审有罪。三个数字对应三个时点，不是矛盾。
4. **18 日中止时刻**：S1＝17:30 顷／S11＝17:40／岛泰三＝17:10（17:19 广播重开）。表述用「17:10—17:40」，见 `03` 开头的时刻口径警告。

- 東京大学文書館『紀要』第43号所收「紛争日誌 その4」（2）（1969-01-01～03-26 翻刻）：`src/utokyo_bunsho_42_紛争日誌4.pdf` 与逐页文本 `.txt`
- 国会会議録検索系统 1969 年「安田講堂」命中 69 件：`src/kokkai_1969Q1_安田講堂.json`
- 犯罪白書 昭和44年版（法務省）：在线引用，见 `02`
- **两本中译本（用户提供 epub，脚本 `extract_epub.py` 抽取）**：`src/shimata_yasuda.txt`（島泰三，178,233 字）、`src/oguma_1968.txt`（小熊英二《1968》，1,697,015 字）；对应来源 S34／S35
- 建筑轮廓：OpenStreetMap（ODbL），`data/key_buildings.geojson`
- 建筑分层与年代：東京大学新聞 2025-11-06「安田講堂竣工100周年」、文化遺産オンライン「東京大学工学部列品館」、東大埋蔵文化財調査室（详见 `02` 的 S21／S22）

> 提示：`src/utokyo_bunsho_37.pdf` 经核实只是《紀要》第43号的目次页，不含正文，保留仅为溯源。
