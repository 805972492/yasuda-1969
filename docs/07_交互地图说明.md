# 07 交互地图说明与使用

> 本资料集有 3 张交互地图，别搞混：
> - `map/安田讲堂攻防战地图.html` —— **构内**战术图（1969-01-18 ～ 01-19，35 小时回放）。本文件讲的是它。
> - `map/1969地形复原图.html` —— 1969 年的构内到底是什么样（已拆/后建/保留 + 讲堂立面分层），见 `10`。
> - `map/东京全城态势图.html` —— **全东京**联动（本郷・神田・駒場・政治媒体，01-15 ～ 01-28），见 `12`。

## 一、打开方式

双击 `map/安田讲堂攻防战地图.html`，用 Chrome / Edge 打开即可。**无需安装任何东西**，但**底图瓦片需要联网**（国土地理院 tile）。断网时页面框架、建筑轮廓、事件列表仍可用，只是没有卫星照片。

## 二、界面与操作

| 区域 | 功能 |
|---|---|
| 中央地图 | 滚轮缩放、拖动平移；点击建筑弹出当日事件（含出处）；右上角图层按钮可切换"地理院 写真 / 地理院 标准图 / OSM 街道图" |
| 时间轴 | 范围 **1969-01-18 06:30 → 01-19 21:00**，步长 5 分钟；拖动即"回放"，未发生的事件变暗 |
| ▶ 播放 | 以约 2.4 小时/秒的速度自动推进（120 ms/步），到 21:00 自动停止 |
| 快捷按钮 | 1/18 15:30 背面突入 / 1/19 17:27 时钟塔突入 / 重置 |
| 事件列表 | 点任一事件＝跳到该时刻并定位到事发点；左侧色条对应类别（入构、攻击、逮捕、转折……） |
| 图例 | 红＝学生据守建筑，蓝＝已解除/警察集结，灰＝中立，橙＝安田讲堂；青色虚线箭头＝机动队进攻轴线 |

## 四、已知局限（请在使用中保留这些说明）

1. **底图是 2020 年代的**：地形（御殿下グラウンド改建、树木、道路）与 1969 年有差异，本图用于理解**方位关系**，不是 1969 年地形复原图。
2. **六个坐标是推定值**：竜岡門、池の端門、農学部正門、弥生門、工学部列品館、法文 2 号館。史料只写"从某门入构"，未给坐标。
3. **讲堂内部分层**（3 楼大讲堂、5 楼屋顶、6 楼阳台、时钟塔）无法在平面图上分层显示，文字说明见 `06`。
4. **时刻精度**：S1 多数只到"5 分钟"或"頃"，1/18 15:30 与 1/19 17:27 等为 5 分钟级；争议时刻（17:30 vs 17:40；60 人 vs 90 人）已在事件说明中并列。
5. **zoom 18 偶发瓦片未加载**：地理院服务器限流，缩放后稍等或退到 zoom 17 即可。

## 五、在 Gentactix 里怎么用这张图

Gentactix 的沙盘底图走 Folium + 卫星瓦片，不直接读本 HTML。两种接法：

1. **轻接法（推荐）**：在 Gentactix 场景设定里把战区中心设为 `35.713428, 139.762297`（安田讲堂），缩放 17—18，再用 `09_Gentactix推演设定.md` 的文字部署。地图 HTML 单独开一个窗口当"参谋图板"。
2. **重接法**：把 `data/key_buildings.geojson` 与 `units.csv` 转成 Folium 的 GeoJSON/Polygon 叠加层，替换 Gentactix 里默认的单位图标。需要改 `app.py` 的渲染函数，属于二次开发，本资料包不提供代码。

## 六、重新生成地图

```powershell
# 依赖：Python 3.10+（本机可用 E:\Gentactix\python\python.exe），无需第三方库
$env:PYTHONIOENCODING="utf-8"
E:\Gentactix\python\python.exe out\build.py
```

脚本会重写 `data/*.csv` 与 `map/安田讲堂攻防战地图.html`；事件表在 `build.py` 的 `ev` 列表中，可直接增删（时间基准：1969-01-18 00:00 起算的分钟数）。
