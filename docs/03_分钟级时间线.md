## 4. 时间线的三个"锚点"（写战报时最常用）

1. **06:30** 总合警备本部设立 / 8,500 人到位——推演第 0 回合的起点。
2. **13:20** 对安田讲堂的正式强攻开始——攻方从"清外围"转入"攻城"的转折。
3. **17:27—17:46** 时钟塔突入至屋顶检举完成——事件终点；此后只有检证与政治余波。
